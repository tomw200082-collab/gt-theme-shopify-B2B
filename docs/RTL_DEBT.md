# RTL_DEBT — מה נשאר גלובלית ב-Horizon מחוץ לנתיב ה-B2B

הנתיב שלנו (`/pages/b2b-landing`, `/pages/b2b-thank-you`) מלא RTL ועברית. החוב הגלובלי:

1. **אין `locales/he.json`** — מחרוזות מערכת של ה-theme (עגלה, חיפוש, skip-link,
   הודעות טופס יצירת קשר, 404) יוצגו באנגלית (en.default). נדרש קובץ תרגום מלא
   (~600 מפתחות) אם Horizon יפורסם אי-פעם כ-theme ראשי.
2. **דפי קטלוג/מוצר/עגלה של Horizon** לא נבדקו ב-RTL — ה-CSS לוגי ברובו (אמור
   להתהפך טוב עם ה-dir שהוספנו), אבל סליידרים/קרוסלות (slideshow, carousel,
   drag-zoom) דורשים בדיקה ידנית של כיוון גרירה וחצים.
3. **פוטר/הדר** — בנויים מבלוקים בעורך; תכנים (תפריטים, טקסטים) טרם הוזנו בעברית
   ל-Horizon — ירושה מהגדרות החנות בלבד.
4. **פונט גלובלי** — Assistant הוחל בהגדרות; כותרות Frank Ruhl Libre חלות רק
   בנתיב ה-B2B (מכוון). אם רוצים אותו גלובלית — להוסיף את ה-font loading ל-layout.
5. **חיפוש/עגלה מודאליים** — מחרוזות באנגלית (נגזרת של סעיף 1) וכיווניות אנימציות
   slide-in לא נבדקה.

כל אלה לא חוסמים את דף הנחיתה. רלוונטיים רק אם Horizon יהפוך ל-theme הראשי.
